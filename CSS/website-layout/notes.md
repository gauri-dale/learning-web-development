# Semantic Tags
Semantic tags in HTML provide meaning and structure to web content, which can then be targeted and styled using CSS. These tags describe the type of content they contain, making the HTML more understandable for both developers and machines (browsers, search engines, assistive technologies). \

They include, but are not limited to: \

- `<header>` = introductory content. \
- `<nav>` = navigation bar, links \
- `<main>` = main content (section, aside, article, div) \
- `<section>` = dependent content. \
- `<aside>` = side content. \
- `<article>` = independent content. \
- `<footer>` = closing content. \
