# Borders

Use `border-style` property.

Types:

- `solid`: for a solid line border \

- `dashed`: for a dashed line border \

- `dotted`: for a dotted line border \

- `double`: for a double border \

- `groove`: to create a 3D grooved border effect. This effect makes the element appear as if it is carved into the page \

- `ridge`: creates a 3D-like border effect that appears extruded or raised from the element (opposite of groove). \

- `inset`: This property creates a 3D-like effect, making the element appear as if it's embedded or pressed into the page. \

- `outset`: creates a 3D effect, making the element appear as if it is coming out of the page. \

- `none`: if something has a border naturally, you can remove it.

# Properties of Borders

- `border-width`: to control width of border (default 1px). \

- `border-color`: to change the color of the border \

- `border-radius`: to round the corners of the border. (max 20px) \

# Using short hand syntax
This is where we include multiple properties in a single line

- Syntax:
border: 3px solid black; <!--width, style, color-->

# Directional short hand syntax

- `border-bottom`: to change the bottom border line \

- `border-top`: to change the top border line \

- `border-left`: to change the left border line \

- `border-right`: to change the right border line \
