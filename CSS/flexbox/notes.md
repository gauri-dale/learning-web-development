# Flex
`display: flex` is a CSS property value that enables the Flexible Box Layout module, commonly known as Flexbox, for an HTML element.

- `flex-direction: row`: displays elements in a row. \
- `flex-direction: row-reverse` : displays elements in reverse order. \

- `flex-direction: column` :displays elements in a column \

- `flex-direction: column-reverse` :displays elements in the reverse order. \
